# Playwright Google Search Automation

## Requirements

Create a production-ready Playwright automation solution that validates Google Search functionality.

The solution shall:

- Navigate to `https://www.google.com`.
- Search for `"brown bear locations"`.
- Verify the search completes successfully.
- Verify the search results are relevant to the requested search term.

## Technology Stack

- Python 3.13+
- Playwright
- pytest

## Architecture

Use the Page Object Model (POM).
