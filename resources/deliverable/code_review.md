# Code Review Deliverable

Review the provided source code and produce a clear engineering code review.

Structure the review using the following sections:

## Summary

Provide a brief overall assessment of the implementation.

## Strengths

Identify aspects of the implementation that are well designed or implemented.

## Findings

Identify meaningful issues or opportunities for improvement.

For each finding, include:

- Severity
- Description
- Impact
- Recommendation

Use the following severity levels:

- Critical
- High
- Medium
- Low

If no meaningful findings exist, explicitly state that.

## Recommendations

Provide a concise list of the most important improvements, ordered by
priority.

Focus on actionable engineering feedback.

Do not include report metadata such as provider, model, execution time, or
review date. That metadata is added separately by the QAlchemy reporting
workflow.
